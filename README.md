# Image Resizer + Circle Crop Tool

A modern, minimal web-based image tool for resizing images and creating circular crops with transparent backgrounds.

## Features

- **Drag & Drop / Upload**: Easy image upload via drag & drop or file selection
- **Resize Controls**: Adjust width and height with optional aspect ratio locking
- **Crop Shapes**: Toggle between rectangle and circle crop shapes
- **Live Preview**: Real-time canvas preview of your changes
- **PNG Download**: Download processed images with transparent backgrounds (for circle crops)
- **Modern UI**: Clean, responsive design with gradient styling

## Usage

1. Open `index.html` in a web browser
2. Upload an image by dragging & dropping or clicking "Select File"
3. Adjust the width and height as needed
4. Toggle "Lock Aspect Ratio" to maintain or unlock proportions
5. Choose between Rectangle or Circle crop shape
6. Click "Download PNG" to save your processed image
7. Use "Reset" to start over with a new image

## Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- Canvas API for image manipulation
- No external dependencies
- Fully client-side processing (no server required)
